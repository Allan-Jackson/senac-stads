🧮 1. Tabuada de um número
Escreva um programa em Java que solicite ao usuário um número inteiro e exiba a tabuada desse número de 1 até 10.

Exemplo:
Entrada: 5
Saída:
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50

🔢 2. Soma dos números pares em um intervalo
Peça ao usuário um número inteiro positivo N. Utilize um laço for para calcular e exibir a soma de todos os números pares de 1 até N.

Exemplo:
Entrada: 10
Saída: 30 (2 + 4 + 6 + 8 + 10)

⭐ 3. Contagem regressiva
Solicite ao usuário um número inteiro positivo e exiba uma contagem regressiva até 0 utilizando for.

Exemplo:
Entrada: 5
Saída:
5
4
3
2
1
0

💻 4. Sistema de cadastro de alunos com média da turma
Crie um algoritmo que simule o cadastro de alunos de uma turma.

O programa deve:

Solicitar ao usuário a quantidade de alunos da turma.
Utilizar um laço for para repetir o processo de cadastro para cada aluno.
Para cada aluno, ler:
Nome
Nota 1
Nota 2
Calcular a média de cada aluno.
Exibir se o aluno foi:
Aprovado (média ≥ 6)
Reprovado (média < 6)
Ao final, mostrar:
A média geral da turma
A quantidade de alunos aprovados
A quantidade de alunos reprovados
🔎 Exemplo de saída (resumido):
Aluno: João → Média: 7.0 → Aprovado
Aluno: Maria → Média: 5.5 → Reprovado

Média da turma: 6.25
Aprovados: 1
Reprovados: 1
