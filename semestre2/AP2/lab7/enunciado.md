# Exercícios LAB-5

ENUNCIADO – Faça uma classe java contendo dois vetores ou use crie um objeto java para armazenar uma lista de nomes, e-mails e RGs; Se quiser você pode criar vetores com valores ao invés de fazer a leitura pelo teclado; 

Todos os vetores devem ter a mesma quantidade de elementos  (o nome completo de uma pessoa, email e rg ).

O programa será comandado por um menu com com as seguintes opções: 

    1 Ler Nome, email e RG;
    2 Exibir tudo lado a lado;
    3 Classificar por nome usando Selection Sort,
    4 classificar por nome usando Insert Sort,
    5 Classificar por RG usando Selection Sort,
    6 Classificar por RG usando Insert Sort,
    7 Classificar por RG usando Merge Sort,
    8 Classificar por e-mail usando Quick Sort,
    9 Buscar um RG usando busca binária,
    10 Buscar um nome usando busca binária.
    0 Finalizar programa.
