## 🛠️ Convenção de Commits (Padrão Monorepo)

Para manter a rastreabilidade e a organização do histórico deste repositório, todos os commits seguem o padrão **Conventional Commits com Escopo**:

$$\text{tipo(materia/projeto): descrição no imperativo}$$

### Exemplos do Padrão:
* `feat(ap1/calculadora): adiciona logica de conversao de bases`
* `fix(pw/landing-page): corrige alinhamento do menu no CSS`
* `docs(pw/portfolio): atualiza links e capturas de tela no README`
* `refactor(pi1/esqueleto-rpg): reorganiza estrutura de pacotes`
